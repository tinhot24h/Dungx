REVIEW STUDIO 0.5 — THỦ CÔNG KHÔNG API / GEMINI / OPENAI

CẬP NHẬT
Đóng bản cũ, giải nén toàn bộ ReviewStudio-v0.5.zip vào thư mục mới có
quyền ghi. Không chạy từ trong ZIP. Đã có Python/FFmpeg thì không cần
cài lại. Thiết kế px bản 0.4 dùng lại nếu cùng trình duyệt/địa chỉ/cổng.
PNG thuộc thư mục cũ cần tải lại khi chuyển thư mục.

CÀI MỘT LẦN
Cần Python 3.11+, FFmpeg/FFprobe có libx264/drawtext. Không cần pip/npm.
Font tiếng Việt kèm sẵn. Python/FFmpeg không kèm ZIP; chưa phải EXE.

Windows 10/11, PowerShell:
  winget install --exact --id Python.Python.3.12
  winget install --exact --id Gyan.FFmpeg
Đóng/mở lại terminal hoặc File Explorer để nhận PATH.
Không có winget: cài Python từ https://www.python.org/downloads/
(chọn Add Python to PATH), FFmpeg từ https://ffmpeg.org/download.html.
Hoặc đặt ffmpeg.exe và ffprobe.exe trong thư mục bin cạnh launch.py.

macOS có Homebrew:
  brew install python ffmpeg
Ubuntu 24.04 / Debian 12 hoặc mới hơn:
  sudo apt update
  sudo apt install python3 ffmpeg

CHẠY
Windows: nhấp đúp START_WINDOWS.bat.
macOS/Linux: trong thư mục giải nén, chạy python3 launch.py.
Hoặc chmod +x START_MAC_LINUX.command rồi ./START_MAC_LINUX.command.
Trình duyệt tự mở http://127.0.0.1:8000. Giữ cửa sổ dòng lệnh mở khi dùng.
Ctrl+C để dừng. Cổng bận: đóng bản cũ hoặc chọn cổng khác:
  PowerShell: $env:PORT='8001'; python launch.py
  macOS/Linux: PORT=8001 python3 launch.py

CHỌN CÁCH DỊCH
Mở tab Dịch & biên tập AI. Nguồn hiện là VĂN BẢN tiếng Trung do bạn dán,
tối đa 8.000 ký tự; chưa tự nghe video, OCR hoặc tạo giọng đọc/MP3.
Chọn Review / Tin tức / Mẹo / Giới thiệu, giọng văn, xưng hô và mục tiêu
15/30/60/90 giây hoặc giữ đủ ý. Thời lượng chỉ là ước tính.

A. THỦ CÔNG — MẶC ĐỊNH, KHÔNG CẦN API KEY
1. Dán nguồn và chọn phong cách, bấm Tạo câu lệnh.
2. Sao chép câu lệnh, mở Gemini hoặc ChatGPT web bằng nút trong tool.
3. Bạn tự đăng nhập và dán câu lệnh trên website đó, chờ câu trả lời.
4. Sao chép đủ JSON gồm literal/script/notes về ô kết quả thủ công,
   bấm Nhập JSON. Có thể nhận JSON được bọc trong khối ```json.
5. Nếu chỉ có văn bản kịch bản: dán trực tiếp vào ô Kịch bản tiếng Việt,
   có thể nhập bản dịch sát nghĩa riêng bằng tay.
6. Duyệt và sửa, sao chép hoặc Tải TXT để tạo MP3 bên ngoài.
Tool không gọi API trong chế độ này. Web AI có hạn mức riêng và cần
Internet; đây không phải AI dịch tự động offline. Không tự điều khiển
web, lấy cookie/token hoặc dùng tài khoản web như API.

B. GEMINI API — CÓ THỂ CÓ HẠN MỨC MIỄN PHÍ
1. Chọn Gemini API. Lấy key Google AI Studio:
   https://aistudio.google.com/apikey
2. Nhập key tại Kết nối API trong ứng dụng, không gửi key trong chat.
3. Model gợi ý gemini-2.5-flash; có thể đổi thành model tài khoản hỗ trợ.
4. Kiểm tra điều kiện, quota và giá hiện hành trước khi gọi:
   https://ai.google.dev/gemini-api/docs/pricing
5. Bấm Dịch & viết lại, chờ hai bản và ghi chú cần kiểm chứng.
Google quyết định hạn mức miễn phí và cước; tool không thể bảo đảm mọi
lượt gọi đều miễn phí. Không tự retry hoặc chuyển sang OpenAI trả phí
khi hết quota. Bạn có thể tự đổi về Thủ công.
Key máy chủ tùy chọn: REVIEW_GEMINI_KEY / GEMINI_API_KEY / GOOGLE_API_KEY.
Model tùy chọn: GEMINI_MODEL. Cần HTTPS tới generativelanguage.googleapis.com.

C. OPENAI API — TÍNH PHÍ RIÊNG
Chọn OpenAI API, nhập key từ https://platform.openai.com/api-keys.
Model mặc định gpt-4.1-mini; có thể đổi nếu model có Responses API và
Structured Outputs. Phí API riêng với ChatGPT Free/Plus.
Key máy chủ: REVIEW_OPENAI_KEY / OPENAI_API_KEY; model: OPENAI_MODEL.
Cần HTTPS tới api.openai.com.

KEY VÀ KẾT QUẢ
Key hai provider giữ riêng trong bộ nhớ phiên, không lưu vào file,
localStorage hoặc ZIP. Tải lại trang cần nhập lại key. Không gửi key qua
chat. Văn bản/cấu hình chỉ gửi tới provider API đã chọn khi bấm dịch;
video và PNG không gửi tới các API dịch.
Bản dịch và kịch bản cần duyệt tên riêng, giá, đơn vị, công dụng và ghi
chú; không coi AI là xác minh sự thật. Không tự đổi giá sang tiền Việt.
Muốn lấy đoạn lên video: bôi đen tối đa 600 ký tự trong ô kịch bản rồi
bấm Đưa đoạn chọn lên video. Toàn bộ kịch bản vẫn giữ để tải TXT.

DỰNG VIDEO
1. Chọn clip tối đa 100 MB / 180 giây. MP4 H.264 được khuyến nghị.
2. Nhập tiêu đề/nội dung; Enter xuống dòng.
3. Tab Nền: màu tùy chọn/chuyển hai màu, vị trí/chiều cao vùng hòa nền.
4. Tab Khung: 6 mẫu, không khung hoặc PNG tĩnh từ máy. PNG tối đa 5 MB,
   4096 px/cạnh, 8 triệu điểm ảnh; giữ tỷ lệ, căn giữa trong hộp. PNG
   động chỉ lấy hình đầu. Màu trong/viền chỉ chỉnh khung dựng sẵn.
5. Tab Tiêu đề/Nội dung: font, màu, cỡ 12–144 px, X/Y, độ rộng, căn dòng,
   viền và khoảng dòng. Chữ/khung di chuyển độc lập, không tự bám nhau.
6. Tab Video: nhập X/Y/W/H. Giữ tỷ lệ 9:16 bật mặc định, tắt để kéo giãn.
7. Chọn lớp cần kéo dưới bản xem trước hoặc dùng số/nút căn giữa hai trục.
8. Xuất MP4, chờ sẵn sàng rồi tải. Kết quả 720x1280, giữ tiếng gốc,
   không thêm CTA và không xóa chữ/watermark có sẵn trong nguồn.
X/Y lấy góc trên trái làm gốc, đơn vị px. X tăng sang phải, Y tăng xuống.
Khung/video có thể ra ngoài canvas và bị cắt. Chữ vượt cạnh phải/chiều
cao sẽ báo lỗi: giảm X/Y, cỡ chữ hoặc tăng độ rộng phù hợp.

DỮ LIỆU VÀ GIỚI HẠN
Thiết kế/văn bản AI tự lưu trên trình duyệt, có nút xóa văn bản AI.
Clip, PNG và kết quả ở .local trong thư mục ứng dụng. Tải kết quả cần
giữ trước khi đóng máy chủ. Chỉ xóa .local khi ứng dụng đã dừng và đã
giữ các tệp cần thiết. Chỉ dùng cục bộ; chưa có đăng nhập, dọn ổ đĩa,
ghép nhiều clip hoặc tự đăng TikTok.

KIỂM TRA
Thủ công đã thử qua HTTP cục bộ và Chromium: tạo prompt, nhập JSON,
copy/TXT không cần key và không gọi API. Gemini/OpenAI kiểm tra bằng
phản hồi giả lập, chưa gọi thật do máy không có key. Chưa xác minh
model/tài khoản cụ thể được miễn phí. Chưa thử trực tiếp Windows/macOS.
